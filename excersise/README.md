# Exercises

This folder contains deliberately separate practice programs. Each operation has its own class, method, and `main` function so the logic is easy to compare.

## Array operations

Open `01-array-operations` and study the files in this order:

1. `01_insertion_class.cpp` - `InsertionExercise::insertAt`
2. `02_deletion_class.cpp` - `DeletionExercise::deleteAt`
3. `03_replacement_class.cpp` - `ReplacementExercise::replaceAt`
4. `04_search_class.cpp` - `SearchExercise::find`
5. `05_traversal_class.cpp` - `TraversalExercise::display`

Each file is a complete C++ program and can be compiled independently.
